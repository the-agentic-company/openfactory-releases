# OpenFactory downloads

Desktop installers for running coding agents on your own computers.

[Download the latest release](https://github.com/the-agentic-company/openfactory-releases/releases/latest)

Choose Apple Silicon or Intel for macOS, the Debian/Ubuntu package for Linux, or the 64-bit Windows installer. These are preview builds. macOS and Windows builds are unsigned and may require approval from your operating system.

Install and sign in to Codex CLI or Claude Code CLI on each computer that runs agents. Provider credentials stay on your computers.

This repository contains release assets only. OpenFactory source development is managed separately.
